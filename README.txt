중국지도 SENSE - 태블릿 수업용

1. index.html을 웹서버/GitHub Pages에 올리면 됩니다.
2. 학생 30명이 같은 링크에 동시에 접속해도 각 기기에서 독립적으로 게임이 진행됩니다.
3. 별도 로그인/DB/서버가 필요하지 않습니다.
4. 지도 경계 데이터는 실행 시 geojson.cn API를 먼저 불러오고 실패하면 GitHub 원본을 시도합니다.
5. 인터넷이 완전히 차단된 학교 환경에서는 지도 데이터 파일을 함께 넣는 오프라인 버전으로 바꿀 수 있습니다.

현재 모드
- 성·자치구 찾기: 10문제, 정답 +100, 오답 -20
- 주요 도시 찾기: 35개 주요 도시
- 60초 스피드

수업용 추천
- 학생 태블릿에서 같은 URL 접속
- '성·자치구 찾기'로 중국 지도 위치 학습
- 이후 '주요 도시 찾기'로 시안/칭다오/구이린/쿤밍/리장 등 복습
